Virtual Piano - Guide

How to Play

Your computer keyboard works like the keys of a piano:

  • Low (left): Z X C V B N M
  • Middle (right): Q W E R T Y U
  • Black keys: S D ... 2 3 4

A MIDI keyboard connected to the computer (Menu, Settings) gets the same features: layer, pedal, arranger and track recording.

Instruments and Layers (Dual Voice)

  • ◄ / ► arrows : Change the Main Instrument
  • ▲ / ▼ arrows : Change Octave
  • Shift + ▲ / ▼ arrows : Change Note Velocity
  • F10 : Turn the Second Layer On/Off
  • Shift + ◄ / ► arrows : Change the Layer Instrument

Audio Controls

  • Space : Sustain Pedal (hold it to let notes ring)
  • Shift + Space : Pedal Lock (off, continuous, smart)
  • F1 / F2 : Transpose (change key)
  • F3 / F4 : Reverb
  • F5 : Metronome (set the BPM)
  • F6 / F7 : Chorus
  • F8 / F9 : Modulation

Favorites

Save your favorite sounds to switch quickly:

  • Save: Ctrl + 0-9
  • Load: Ctrl + Shift + 0-9

Arranger (Automatic Accompaniment)

While the arranger is on, the keys below the split point (C4 at first, which is the row from Z to M) stop sounding and choose the chord instead. Drums, bass and harmony play by themselves in the selected style, and the rest of the keyboard is free for the melody. The chord stays after you release the keys.

  • F11 : Start / Stop the arranger
  • Shift + F11 : Start with an intro, or finish with an ending if it is already playing
  • F12 : Fill-in
  • Shift + F12 : Switch variation A/B (with a fill-in)
  • Ctrl + ◄ / ► arrows : Change style (while playing, it changes on the next bar)
  • Ctrl + ▲ / ▼ arrows : Tempo in steps of 5 (with Shift, steps of 1)
  • Ctrl + PageUp / PageDown : Accompaniment volume
  • Ctrl + Shift + ◄ / ► arrows : Split point

Chords: a single key plays the major chord; Shift + the key plays the minor chord; root plus minor third plays the minor chord; root plus seventh plays the seventh chord. With three or more keys the program recognizes major, minor, seventh, diminished, augmented, sus and sixth chords, in any inversion.

Record a Style by Playing

In the Arranger menu choose Record a New Style by Playing (starts from nothing) or Re-record Parts of the Current Style (starts from an existing style). You record one part at a time, always playing in C major; afterwards the arranger moves everything to whatever chord you play.

The parts are: Drums, Bass, Chords and Pad of variation A, the same four of variation B, and the Fill-in. Whatever is left empty in variation B and in the fill-in uses variation A.

  • Ctrl + T : Next part (with Shift, the previous one)
  • Ctrl + R : Record. There is a one-bar count-in; play, then press it again to stop. It records up to 4 bars.
  • Ctrl + P or F11 : Listen to the style as it is
  • Ctrl + Shift + P : Listen to the selected part only (just the bass, for instance)
  • Ctrl + L : Listen to the last recording only: just what you have just recorded (the snare, for instance), without what was already there
  • Ctrl + Z : Undo the last recording. Got the snare wrong? Only that take goes away; the hi-hat and cymbal recorded before it stay. Press it again to go back one more recording.
  • Ctrl + Delete : Erase the selected part
  • Ctrl + ▲ / ▼ arrows : Tempo of the style
  • Ctrl + S : Save the style and leave
  • Esc : Leave without saving

While the recorder is open, the Style Recorder menu has the same commands, plus Erase Everything and Start Over.

  • Drums and Fill-in: the keys become the drum kit: Z kick, S rim, X snare, D clap, G closed hi-hat, H pedal hi-hat, J open hi-hat, V B N M , . toms, L crash, ; ride. Every recording adds pieces to what is already there, so you can record kick and snare first and the hi-hat afterwards.
  • Bass: play one note at a time. C is the root, E the third, G the fifth, A or B flat the seventh/sixth, and the upper C the octave.
  • Chords and Pad: two or more keys together count as the whole chord. A single key becomes an arpeggio: C, E and G are the first, second and third notes of the chord.
  • The instrument of the part is the one selected when you record it, and what you play is snapped to the time grid of the style.

Edit Styles as Text

Every style is a text file, including the ones you record by playing. In the Arranger menu choose Edit a Copy of the Current Style as Text: the program copies the selected style to the folder Documents, Piano Virtual, Styles and opens the copy in Notepad, with the instructions at the top of the file. Edit it, save, then choose Reload Styles.

Every pattern has one character per step. With 4 steps per beat, a 4/4 bar has 16 characters:

[drums]
kick  = x... .... x.x. ....
snare = .... x... .... x...
hat   = x.x. x.x. x.x. x.x.

[bass]
program = 33
a = 1--- --1. ..1- 5-3.
  • Drums: . silence, x hit, X accent, o soft hit
  • Bass: 1 root, 3 third, 5 fifth, 7 seventh or sixth, 8 octave
  • Chords: x whole chord, 1 to 4 single notes (arpeggio)
  • - keeps the previous note sounding

Song (Track Recording)

Record up to 6 tracks, one at a time, each with its own instrument. While you record a track, the others play. If the arranger is on during the recording, the accompaniment is recorded too, on a track of its own.

  • Ctrl + R : Record / stop recording on the selected track (there is a one-bar count-in)
  • Ctrl + P : Play / Stop
  • Ctrl + T : Next track (with Shift, the previous one)
  • Ctrl + M : Mute / unmute the selected track
  • Ctrl + Q : Quantize the selected track: snaps the notes to the time grid (eighth, sixteenth, triplet). The strength sets how far: 100% lands on the grid, 50% only moves half way. Song, Undo Quantize brings back what you played.
  • Ctrl + N / O / S : New song / Open / Save as a MIDI file

Recording again on a track replaces what was on it. To record the accompaniment again, select the accompaniment track and use Song, Clear Track.

Recording tip: The metronome is heard on your sound device, but it does not go into the recorded audio file.
